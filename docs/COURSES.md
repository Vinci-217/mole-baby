# 学会新本领，布置自己的小屋

这是本项目的桌宠课程设计。三系变身使用原页游公开客户端动画，魔术盒与过渡烟雾是自制共用图层；课时、进度、工作报酬属于桌宠玩法，不等同于原服数值。[素材出处与导出记录](../research/original-element-skills.md)。

小屋底栏点「学院」。初级起可以上基础课程；需要健康至少35、饱食和水分至少25、精力至少30；不足时显示门槛及当前数值。每门课完成一节即掌握并获得证书，不需重复学习；中途结束不算完成。所有课程均为3分钟，进行中在小屋和桌面显示进度条及倒计时；重开后继续，只结算一次。旧版正在进行的课程保留已经学习的时间，采用3分钟截止时间；旧规则下已经到期的课程直接结算。

魔术盒从原形冒烟遮住后变成蓝紫色盒子，再冒烟恢复。眼睛以外不保留拉姆身体特征。所有阶段复用4张盒子、16张烟，原形、原色和衣服独立，表演不会修改装扮存档。桌面「玩耍」保留3×3基本操作；向下滚动可找到已学会的三系法术。第五阶段形态可以直接在桌面施放，结束恢复原形、原色和装扮。

魔法法杖仅通过魔法入门课获得，结业后自动放进衣橱。已结业的旧存档自动补发；未结业且以前购买过的旧法杖收回、退还65摩尔豆，完成课程再获得。法杖不在购买流程中出售，获得后可永久穿戴。

餐厅要求精力至少31点，包含开工消耗及完成前的自然消耗，避免刚开工就困睡。每班2分钟，完成获得180摩尔豆。工资只发一次；中途结束不领。上课与打工同时只能做一件；睡觉或自动入睡会中断未完成的活动。醒来点「轻轻叫醒」。

点小屋背景上方「布置小屋」，直接在实际背景拖家具，右侧工具箱购买、摆放或收回。新增19件原版家具与5间原版房型，旧版8件摆设仍保留。墙饰与证书放墙面，其他家具放地面；露天场景隐藏墙饰，回室内恢复。拖动松手自动保存，存档导入导出也保留布置。布置入口不在页面选项栏。

小屋中点击地面活动区，拉姆会走或飞到标记处；种子由用户指令触发小跳，不会自行散步。墙面与底部功能栏不作为目的地。移动中可再次点击改方向，摸摸、睡觉、上课或打开面板会停下；布置家具时关闭地面移动。键盘聚焦地面后，方向键也能移动。系统启用减少动态效果时直接移到目标。BGM正在播放时进入小屋继续原进度；暂停或关闭后重新播放才从头开始，普通点击不会重置播放进度。

桌面第一个按钮为「状态」，显示六项数值；关闭按钮左边「?」显示与实际状态计算共用的每小时规则。背包独立显示食物、饮品、清洁和药水四类用品，不再包含状态分类。

小屋上方「全屏查看」进入全屏，可再次点击或按Esc退出；回到桌面与缩到托盘时会先退出全屏，恢复原窗口尺寸。

「设置 → 当前成长阶段」可选自动成长或固定形态，并选择起始阶段。先点击「应用成长设置」，确认后才保存；取消或Esc不会改动当前设置。同阶段切换保留已有进度，固定期间暂停累计；选择其他阶段从该阶段起点开始。仅切换成长模式保留正在进行的课程／工作与外出，更换阶段则中断当前活动或召回。

成长界面和设置均显示当前阶段的成长百分比，以及距下一阶段所需的健康清醒时间；睡眠或状态不足会暂停成长，所以剩余时长不是固定的日历截止时间。进度自动保存，重新打开后继续。

设置可选正向或倒数计时，均按所设分钟数结束提醒。正向从零累计，倒数从目标时长递减；完成及手动结束的实际时长保存在「回忆 → 计时记录」。更改方向、时长或关闭提醒会结束当前计时，重新开始须点击按钮。

三系魔法整段保持固定比例，大特效可以越过原宠物区域；桌面施放时临时扩展透明窗口，结束恢复。睡眠每分钟恢复10点精力，达到85自然醒来。小游戏会从当前阶段可用的食物、饮品、清洁用品中随机奖励一件，分数决定摩尔豆；结算显示实际入包结果。鼠标悬停系统托盘图标可查看六项状态及睡觉/上课/打工状态，隐藏窗口后继续更新。
