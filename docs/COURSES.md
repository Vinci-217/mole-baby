# 学会新本领，布置自己的小屋

这是本项目的桌宠课程设计。角色身体沿用原页游动画，课程时长、工作报酬、进度和新法术道具属于桌宠玩法适配，不是原服规则。

进入小屋，点底栏「学院」。种子长成初级后即可上课；需要吃饱、喝足、精力至少30。每次上一节，三节结业，不自动连上下一节。完成的课时会保存，尚在进行的一节重开后继续计时；主动结束不增加课时。

| 课程 | 每节 | 前置 | 结业后 |
| --- | --- | --- | --- |
| 语言课 | 2分钟 | 初级 | 从bibobibo变为中文陪伴短句 |
| 英文课 | 3分钟 | 语言课 | 英文问候 |
| 魔术课 | 3分钟 | 语言课 | 帽子变花、原有魔法变装练习 |
| 旋风术 | 4分钟 | 魔术课 | 施放绿色旋风 |
| 流火术 | 4分钟 | 魔术课 | 施放火浪 |
| 寒冰术 | 4分钟 | 魔术课 | 召出冰晶 |
| 陨石术 | 4分钟 | 魔术课 | 落石、命中和消散 |

结业后到学院点「展示本领」，拉姆会在当前场景表演。法术是安全的屏幕动画，不操作其他应用。每门课还有一张对应结业证书，出现在「布置小屋 → 墙饰与证书」。

桌面「玩耍」里有「餐厅打工」；小屋「游戏」也有入口。每班2分钟，拉姆端盘、送餐、收拾，完成获得180摩尔豆。工作保存到本地，重新打开可以继续结算，工资只发一次；中途结束不领工资。上课和打工同时只做一件，困倦、饥渴时先照料。

小屋「布置小屋」中可买八件摆设，用摩尔豆支付；证书通过课程获得。已拥有的摆设可放入、拖动或收回箱子。墙饰和证书的下缘限制在墙面区域，地毯、软垫、绿植、书架、茶几和灯的落脚点限制在地面区域；不会互换类型。野餐地和露天观星场景不显示墙饰，回到室内后恢复原来的摆放。拖动保留抓取位置，松手后保存。物品在当前宠物的存档中，导入导出也一起保留。

桌面「玩耍 → 睡一会儿」或小屋「游戏 → 睡一会儿」可以主动休息。会中断尚未完成的课程或工作；自动困倦入睡继续保留。睡着后点「轻轻叫醒」。精力充足时手动睡觉也至少休息一分钟，避免下一次状态检查立刻醒来。
