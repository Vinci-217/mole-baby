# 本地形态调试

运行 `npm run dev`，打开网页右下角的「本地调试」开关，再从小屋「成长」切换阶段和神力形态。开启后可以直接选择种子、初级、中级、高级，以及五种神力形态，不必等待成长。仍需点击「应用成长设置」并确认，以便检查实际切换流程。

调试模式把当前网页存档复制到当前标签页的独立测试区；没有存档时会创建测试拉姆。调试中的形态、成长、物品和回忆只写入测试区。刷新保留这次测试，关闭开关后重新读取原存档，关闭标签页则结束测试会话。不要将测试区导出的文件当成正式存档。

此开关默认关闭，仅在 Vite 开发服务或显式启用的网页预览构建中出现：

```sh
VITE_LOCAL_DEBUG=1 npm run build
npm run preview -- --port 5173 --strictPort
```

正常 `npm run build` 以及正式 Windows、Mac 和 Android 构建不启用此入口。原生客户端继续使用原来的存档桥接，不会被网页调试存储替换。

独立看书动画预览位于 `/?preview=reading`，可以查看九种形态、桌面／小屋大小、黄／蓝配色和一次完整的18秒读书过程；此页面不操作玩家存档。
