# 增量更新实现与自测 · v0.31.4

本实现源自 `preview/incremental-updates`，已获本轮发布授权，纳入 v0.31.4 构建。以下保留发布前的独立自测数据，正式成品验收另见[本版发布记录](../research/release-0.31.4-validation.md)。本版同时包含此前的桌面状态小窗和 Windows 窗口/玩耍修复。

## 已实现

- Windows 常规版、兼容 x64/ia32：使用 electron-updater 的 NSIS 分块下载，从旧安装包复制可复用内容，只下载变化部分；SHA512 校验通过后沿用原有安装和重启流程。
- 当前 Mac 本地签名版：下载变化的字节区间，本地重组完整 DMG；完整 SHA256 校验通过后才允许打开。保持当前由用户替换应用的方式。
- 新旧安装包及分块索引均固定到对应版本目录，支持从旧版本直接更新，避免在 `latest` 中寻找历史索引。
- 使用单区间 Range，适配 GitHub 及未来 OSS/COS 下载源。缺缓存、索引异常、Range 不支持或增量校验失败时回退完整下载。
- 保留下载与安装分别确认、安装前存档回执；退出不会自行安装。关闭程序时取消下载，清理未完成文件。
- 设置显示增量/完整下载、当前传输量和复用量；Mac 成功下载后清理较旧的安装包，保留当前版本基准和待更新包。
- 发布工作流在最终安装包签名/公证和校验之后生成七个 blockmap，再统一核对和上传。预览测试工作流不包含发布步骤。

复用更新库内部的计划器和 Provider 接口，因此将 `electron-updater` 固定到 6.8.11，并增加对应回归检查。构建器仍按锁文件使用 26.15.3。

## 如何过渡

旧客户端把“完整下载”的逻辑写在本地，因此首次升级到支持增量的版本仍可能完整下载一次。新的 Windows 安装器会建立基准；通过应用内下载的 Mac DMG 可在之后更新中复用。从浏览器手动安装、清理缓存或切换架构后，可能需要完整下载建立基准。

首次安装包和最终安装体积不会直接缩小，增量重组也需要暂存空间。大素材独立缓存属于后续改造，本轮没有拆除素材或降低动画质量。

## 下载源

本轮继续使用本仓库 GitHub Releases，不接入国内加速。首次安装和手动覆盖更新，优先使用[最新正式版下载页](https://github.com/Vinci-217/mole-baby/releases/latest)，选择与系统和架构匹配的 EXE/DMG；`.blockmap` 由更新器读取，无需用户手动操作。
