# 拉姆餐厅打工（预览）

从小屋下方的「餐厅」或「一起玩耍 → 餐厅打工」进入。打开后自动播放，不需要备菜、购买菜谱或管理员工。

动画依次展示客人进店、坐下点餐、拉姆取餐、端盘送餐、上菜、客人用餐和离开。拉姆空手返回，餐盘清除后接待下一位客人；客人的配色、座位和菜品随轮次变化。

场景右侧只保留一个「换背景」按钮，点击依次切换 15 套原餐厅背景，选择单独保存在本机。退出按钮在窗口右上角，也可按 Escape 返回小屋。断网或进入后台时暂停动画，恢复后继续，不追算离线时间。

## 素材与适配

角色服装、方向动作、客人进餐帧、餐盘、背景与背景音乐来自已核对的原客户端素材。服务员采用玩家拉姆的身体配色，服装和托盘保持原色。完整进店、送餐、用餐、离场路线与时序由本项目在本地编排，并非一段官方完整游戏录像，也不连接淘米游戏服务器。

素材出处见 `public/assets/original/restaurant/sources.json` 与 [原版素材调查](../research/restaurant-original-assets.md)。原件留在本地素材库，不改写 `local-assets/raw/`。原素材权利归淘米等原权利方所有。

## 存档

当前餐厅仅展示打工动画，不扣摩尔豆、不结算收益，也不修改旧餐厅的菜品、员工、经营进度。旧经营模块保留在代码中，但不再从界面进入。

宠物仍使用原 `ramu-house-save-v1` 存档，颜色、成长形态、物品、家具和回忆沿用原记录。背景偏好单独使用 `ramu-restaurant-background-v1`，不会改动宠物存档。

`?preview=restaurant` 为独立预览入口：可读取旧体验档 `ramu-restaurant-review-v1`，没有体验档时使用一只蓝色拉姆；不会读取、写入或覆盖正式宠物档。

## 验证

```sh
npm test
npm run build
node scripts/restaurant/work-showcase-check.cjs # 需要 localhost:5173 生产预览
```

时间轴测试覆盖全部背景的阶段衔接、送餐后上菜、用餐后清台、客人离场与循环首尾。浏览器检查覆盖桌面和手机宽度、背景切换与重开、断网和后台暂停、退出、正式存档与调色结果保留。实体 Windows、macOS 和手机仍需本机验收。

## 桌面打工展示

桌面端在「一起玩耍 → 餐厅打工」后会继续停留在桌面，显示一个轻量流程：左侧原餐厅灶台、右侧原餐桌，拉姆从灶台取餐、端盘到桌边，再空手返回。点击小场景可进入完整餐厅动画，点击「结束工作」会取消本次工作且不发工资。

桌面演示图和 GIF 位于 `artifacts/restaurant-work-details/`。它们使用同一套运行时组件和素材，不是单独制作的宣传动画。
