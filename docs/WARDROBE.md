# 拉姆的小衣橱

小屋点击「衣橱」可以试戴，预览左右移动、睡觉、摸摸、开心、不高兴、吃东西和玩球，再用摩尔豆购买。试戴和动作预览不扣豆，不消耗用品，也不增加成长。购买、试戴和穿脱均在小屋衣橱；桌面小背包只保留用品。

v0.24 提供9件：庆生小帽、金色羽毛、紫色魔法帽、魔法法杖、魔法书、粉兔帽、火焰羽翼、彩虹眼罩、皇冠猫耳。名称、价格及桌宠安装位置属于本地设计，不代表核实了原服务器商品名和售价。衣橱每页九格，第二页可找到皇冠猫耳。

## 动作与形态

八件使用原客户端 `petcloth/swf2` 的服饰图形和时间轴；庆生小帽保留原静态配饰。紫色魔法帽包含之前遗漏的黄色星星。身体、眼睛和嘴仍由原角色图集播放，装扮跟随同一身体源帧，避免把预览商品图里的另一张脸盖在拉姆上。

种子、初级、中级、高级与四种神力形态分别适配。大帽子会遮住原叶冠，书与魔杖放在身侧，花盆保持直立。装扮保留自己的原色，身体仍保持领养或换色药水选定的颜色。吃东西、玩球时换装保留当前动作与进度。

原服饰没有覆盖所有种子、神力形态与照料动作。有原动作时读取相应姿态；缺失时使用原正面姿态，按当前身体位置适配。帽子、兜帽、手持物分别安装；这不是原客户端完整服装系统或衣料模拟，也没有把一套大套装强行覆盖所有形态。当前为一个装扮位，不能同时叠穿多件。
