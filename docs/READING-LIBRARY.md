# 小屋书架全部藏书

收录 61 册图书、手册和纪念册，以及 184 期早期《摩尔时报》。共 245 个书架条目、18 页，每层最多 7 本。

共有 3873 张阅读画面，包含封面、正文、封底和部分原过渡。书目来自本地原客户端档案，保留唯一来源。已筛查书名和可提取的正文，移出涉及魔灵或摩灵的条目。

在家具仓库摆放「拉姆书架」后，点击竖放的书脊取书。用书架下方的箭头换页，或点页码跳转。打开书本后可以点击左右下角翻页。

书页排版、素材来源及测试说明见 [小屋家具书架预览](READING-SHELF-DEMO.md)。
