拉姆 Windows 启动说明

推荐：下载名字以 -Setup.exe 结尾的安装包。安装完成后，从桌面或开始菜单打开“拉姆”。
安装目录内的“拉姆.lnk”或“拉姆.exe”也是启动入口；兼容版对应“拉姆兼容版”。
如果旧快捷方式提示找不到程序，请直接运行新版 Setup.exe 覆盖安装，安装器会重建入口，无需先卸载，也不要删除存档。

如果下载的是便携版 ZIP：
1. 右键 ZIP，选择“全部解压”。
2. 打开完整解压后的文件夹，双击“拉姆.exe”（兼容版是“拉姆兼容版.exe”）。
3. 也可双击同目录的“启动拉姆.cmd”，它会检查主程序是否齐全。
4. 不要在压缩包内部运行，不要单独移动 exe，旁边的 resources、locales、DLL 等文件必须一起保留。
5. 运行后在屏幕右下角托盘的“∧”里找拉姆图标，可选“显示拉姆”或“进入小屋”。

如果解压后只有 src、public、package.json 等文件，你下载的是 Source code（源代码），它不是 Windows 应用包，没有可直接运行的 exe。请回到 GitHub Releases 下载 -Setup.exe 或 -x64.zip。

不要为了安装/升级删除旧存档，也无需先卸载旧版。
