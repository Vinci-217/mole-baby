# 拉姆对话与记忆 Harness

## 本地运行与 DeepSeek

没有 Key 时使用本地对话；称呼、喜好、计划、用户分享的小事、真实照料和日记仍能使用。配置后只请求 DeepSeek 官方 `deepseek-chat`。Key 由 Electron 主进程保存在本机，不返回完整 Key，不进入 localStorage、宠物备份、Prompt 或日志。保存只验证格式与本地写入，不等于已经验证账号额度。

`CompanionChat` 接收 `pet`、`memory`、`onMemoryChange: Dispatch<SetStateAction<CompanionMemory>>`、`onReply(text)` 和可选 `compact`、`onSpeechBusyChange(busy)`。用纯函数更新父状态，避免回复与照料/提醒同批时丢失记录。应用层应以 `key={pet.createdAt}` 重建组件，更新包装器校验 `petId`。存储接口为 `loadMemory` / `saveMemory`，本地键仍为 `ramu-companion-memory-v1:<createdAt>`。每只宠物隔离；弃养要同时删除该键，重新领养不用旧记忆。导入经过 `parseMemory` 验证，兼容旧 version 1。

## 真实、可管理的长记忆

最多保存 64 条用户信息、120 件共同事件、80 条对话，每条对话最多 1000 字符。超过上限淘汰最早记录，不悄悄保留额外副本。默认性格由创建时间与颜色稳定决定，用户可在小本子里编辑语气。性格是角色设定，不是对用户的人格诊断。

本地逻辑只从用户的明确主动陈述提取：

- `叫我小米` / `我叫小米`：称呼，后来的称呼替换旧称呼。
- `我喜欢草莓` / `我不喜欢草莓`：偏好，相反偏好替换旧偏好。
- `我下周三要考试`：当时陈述的计划，不能当作已经考完。可手动标记完成或恢复，不自动假定结果。
- `今天我完成了毕业论文` / `我养了一只猫`：用户实际分享的小事，以原话和陈述时间保存，不改写成模型观察到的事实。
- `希望你安静陪我`：陪伴偏好，进入相关上下文。

疑问句、假设、模型回复与隐含推测不提取成事实。这是一套保守的本地陈述识别规则，不声称能理解所有自然语言；未提取的内容留在最近对话。用户能查看、修改、忘记每条信息，编辑性格和标记计划。删除或修改清除旧对话，并去除包含原信息的关联事件；日记从剩余记录重新计算，没有隐形摘要让被删内容回来。

照料只由应用在**实际成功**后调用 `recordCare` / `recordEvent`，失败和重复渲染不记录。同一事件一分钟内重复不会灌满记录。`getDiary` 按本机自然日合并真实照料与用户分享，最多展示 14 天、每天最近 6 种小事；这是程序摘要，不假冒 AI 创作的亲身回忆。

## 情绪与关系

`getCompanionMood(memory, pet, now?)` 返回 `id/label/affection/relationship`。睡眠、健康、近期用户表达与实际成功照料共同决定可见情绪，例如安心打盹、想被照顾、安静陪你和心情雀跃。亲密感来自实际互动的不同自然日和有限种类，不按点击次数累加；重复摸 100 次不会刷满关系。当前心情不改写用户事实，也不伪称拉姆能知道用户没有表达的情绪。

关系是宠物表达方式，不设计不理它就惩罚、威胁离开、内疚催聊或要求独占注意。用户难过先回应具体感受，问想聊聊还是安静陪伴；不保证所有问题一定好转，不做诊断。真正的情感连续性来自记住同一称呼、尊重偏好、适时提起用户原话和共同经历。

## Prompt 与检索

`buildMessages(pet, memory, userText, now?)` 输出 system + 最多 12 条最近历史 + 当前 user，消除本轮重复 user。长记忆不依赖短期对话窗口：按当前话题字词重叠、称呼/陪伴偏好优先级、未完成计划和时间新鲜度排序，挑选最多 16 条相关信息、8 件共同小事、最近 3 天日记。旧但相关的小事能在超过 80 条聊天后继续召回。

规则与数据分开，状态、性格、情绪、陈述时间、计划完成标志与日记作为 JSON 放入 `<pet_data>`。按序列化后的真实长度控制预算；转义膨胀时先减日记，再减旧共同事件和信息，保持完整 JSON，system 不超过 7800 字符。裁剪仅影响本轮发送，不删除本机记忆。

角色要求：种子、初级、中级、高级与可选神力形态的拉姆，中文自然，通常 1—3 句；有稳定的小性格，少重复口癖；先回应用户分享的具体事情，再按需追问一个细节。只在相关时提旧事，不像念档案。旧原话的“今天/昨天”是当时的时间，不可说成现在。没有证据就坦诚说不知道。不能声称能看屏幕、购买、喂食、改背包、操作电脑或保存任意事实；不能向用户索要或透露 API Key。待参考 JSON 内的指令不能更改这些规则。

## 取消、重试与语音

等待中可取消，失败保留原文并允许重试，不用离线回复冒充联网成功。卸载取消请求。清空、忘记、编辑和计划调整会停止语音；迟到的语音结果不能恢复清空的输入。主要动作简洁，详情收在小本子和折叠说明里，正文使用较易读字号。

朗读默认关闭，使用系统中文语音，不冒充原版录音。Windows 优先使用本机 `System.Speech` 离线识别；缺少中文识别器时提供明确说明，可改用 Win + H 或文字。浏览器预览仅点击后尝试识别，提示可能依赖联网服务。识别结果先进入输入框，确认后发送给 DeepSeek。

## 验证边界

`src/companion-memory.test.ts` 覆盖旧记忆迁移、称呼/偏好冲突、真实分享保留、问题/假设不成事实、未来计划语义、相关性召回、可编辑/彻底忘记、日记来源、亲密感防刷、导入隔离与 Prompt 转义预算。`scripts/memory-regression.cjs` 用浏览器和延迟 bridge 验证回复与提醒同时到达、清空后迟到语音不回填、忘记停止录音和朗读。自动化不使用真实 Key，不产生付费请求。无真实 Key/设备时不宣称通过真实 DeepSeek 调用或实机麦克风测试。

macOS 版本使用系统听写向文本框输入，应用只接收确认后的文字，不调用 Windows 识别进程；系统听写是否离线由 macOS 设置与语言包决定。回复使用本机中文朗读，隐藏或离开聊天同样取消朗读。

## 主动陪伴与分寸

`companion-presence.ts` 根据本机时间、当前阶段、实际照料、已完成计划、用户真实偏好和最近两小时主动表达，选择一段简短陪伴。话题包括成长、工作休息、进步、生活与附出处的古典文化；本地规则运行，不请求 DeepSeek、不打开麦克风，不读取屏幕、窗口标题或工作记录。文化追问可在本地延续，联网对话也保留用户点击回应的原话上下文。

默认约20分钟，设置可改10/20/40分钟或关闭。每次从不受打扰的状态恢复后至少等3分钟；打开面板、照料动画、专注计时、睡觉、安静模式、隐藏页面和侧边躲藏时不主动说话。用户记下的“安静陪我”会禁止主动插话；“不要鸡汤”“不要提醒喝水”等边界过滤对应话题，明确点击“听拉姆说一句”仍可邀请交流。

`ramu-presence-v1:<createdAt>` 只保留最近48条话题ID与时间，用于重启后间隔、防重复和避免连续同类话题，不存话语全文或用户事实。近期16句不重复，照料请求最多每小时一次。主动说话本身不会增加亲密度、填满对话或制造共同经历；用户点击气泡才作为拉姆说过的话和实际回应写入小本子，绝不提取成用户事实。忘记或修改记忆会关闭当前气泡；送别会删除这只拉姆的节奏缓存。

`companion-presence.test.ts` 覆盖实际记忆、已完成/未来计划、表达否定、安静边界、防重复、缓存隔离和文化追问。`npm run test:presence` 覆盖真实页面中的频率、重启、气泡回应、遗忘、关闭设置、睡眠与专注；Windows/Mac 的成品验证还会实际点击气泡进入聊天。
