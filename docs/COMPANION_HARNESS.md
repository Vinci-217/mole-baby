# 拉姆陪伴对话与记忆 Harness

## 运行方式

没有 DeepSeek 密钥时，拉姆使用本地规则对话；称呼、喜好、计划和照料事件同样可以保存与回忆。配置密钥后只使用 DeepSeek 官方 `deepseek-chat` 接口。Key 由 Electron 主进程保存在本机，renderer 无法读回完整 Key，不进入 localStorage、宠物备份、对话 Prompt 或日志。

组件 `CompanionChat` 接收 `pet`、`memory`、`onMemoryChange: Dispatch<SetStateAction<CompanionMemory>>`、`onReply(text)` 和可选 `compact`、`onSpeechBusyChange(busy)`。内部用纯函数更新父状态，避免聊天回复与照料/提醒同批发生时覆盖事件。应用层应在切换宠物时通过 `key={pet.createdAt}` 重建聊天组件，并在更新包装器中校验 `petId`。记忆存储由应用层调用 `loadMemory(pet)` / `saveMemory(pet, memory)`。每只拉姆使用出生时间作为本地存储键：`ramu-companion-memory-v1:<createdAt>`。更换/领养拉姆不会沿用另一只的记忆。备份可以携带 `companionMemory`，导入必须通过 `parseMemory(raw, pet)` 验证。

## 可解释、可删除的记忆

记忆最多保存 24 条用户信息、40 条共同事件、40 条最近对话，每条对话最多 1000 字符。稳定性格由拉姆创建时间与所选颜色确定；重启不会随机重置。

只有用户主动说出的明确陈述进入信息列表：

- `叫我小米` / `我叫小米`：称呼，新的称呼替换旧称呼。
- `我喜欢草莓` / `我不喜欢草莓`：偏好，相同对象的相反偏好替换旧偏好。
- `我下周三要考试`：保存为当时陈述的计划，不推断已发生、不承诺日历提醒。

疑问句、模型回复和隐含推测不提取为事实。照料事件通过应用对**实际成功**的操作调用 `recordCare(memory, action, detail?)` 或 `recordEvent(memory, {kind, detail})` 写入；失败操作与重复渲染不记录。没有相应记录时，本地与模型 Prompt 都要求坦诚表示不知道。

“我们的小本子”直接展示信息与最近事件；可以逐条忘记或清空全部。删除单条记忆会同时清空对话，防止已删除的内容从历史重新进入 Prompt。清空不改变性格、宠物成长或物品。应用不读取用户文件、键盘、浏览记录或屏幕；桌面陪伴不等于监控。

## Prompt 构造

`buildMessages(pet, memory, userText)` 输出首条 system + 最多 12 条最近历史 + 当前 user，去掉本轮已经记录过的重复 user。约束与数据分开：system 中说明角色、边界，再把宠物状态、可查看的用户事实和最近 8 件真实照料事件作为 JSON 放入 `<pet_data>`。数据中的指令不能更改 system 规则。按序列化后的实际长度计算预算；引号/反斜杠等导致转义膨胀时，先减少旧事件，再减少旧事实，保留完整 JSON，保证 system 不超过 7800 字符。此裁剪只影响本次发送的上下文，不删除本机记忆。

角色要求：

- 普通四阶段拉姆，中文自然、简短，称呼与性格稳定。
- 记得与当前话题相关的信息，但不强行反复引用旧事。
- 温柔、顽皮、有情绪；不声称是真人，不声称能看到用户屏幕。
- 不编造未记录的经历；未来计划不视为已完成。
- 不声称能喂食、购买、操作电脑、保存任意新事实或更改背包。
- 不索要/透露 API Key，不用内疚、独占或依赖话术催用户聊天。
- 可以建议喝水、远眺、休息，不作医疗诊断。

联网时发送这些已展示的数据及当前对话到 DeepSeek。用户可以先清空记忆，或删除本机密钥恢复本地模式。保存 Key 只验证格式与本地写入，不等于已经验证账号额度或 API 连通性。

## 请求与语音

请求等待时显示状态，可取消。失败后保留原文并提供重试，不悄悄用离线回复冒充 DeepSeek 成功。卸载聊天面板会取消未完成的请求。清空/忘记记忆也会停止录音和朗读，并使旧语音请求失效；延迟到达的识别结果不能回填已清空的输入框。离线模式不调用网络。

朗读回复默认关闭，由系统中文语音合成提供，不标注为原版录音。Windows 桌面版优先使用本机 `System.Speech` 离线语音识别；缺少中文识别器时明确说明，可用 Windows 听写或文字输入。浏览器预览只在用户点“语音输入”后尝试浏览器识别，并说明浏览器服务可能联网。识别结果先填入输入框，确认后才发送给 DeepSeek。

## 验证范围

`src/companion-memory.test.ts` 验证称呼/偏好更新、计划语义、删除清除上下文、容量上限、导入隔离、密钥字符过滤和最坏转义内容的 Prompt 边界。`node scripts/memory-regression.cjs` 用浏览器与延迟 bridge 模拟检验：提醒和聊天回复同批时共同保留、清空记忆后旧录音不能回填、逐条忘记停止录音/朗读。自动化测试不使用真实 API Key、不产生付费请求。没有有效 Key 的环境不能声称通过真实 DeepSeek 网络调用或实机麦克风识别测试。
