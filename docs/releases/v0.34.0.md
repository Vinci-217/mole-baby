## 缓存与显示

切换桌面和小屋时，支持状态保留移动的运行时复用同一 iframe 文档、WASM 及原片 AVM；未就绪的播放器不进入缓存，闲置播放器暂停并静音，最多保留两个。旧版 WebView/Windows 兼容运行时使用正常加载和已缓存外观衔接。各成长阶段使用按版本、形态、颜色和尺寸区分的无损配色图集缓存；不减帧、不缩小高清原件。缓存独立于玩家存档。

九种形态在重新加载页面、清空模块内存并阻断原始中性图/蒙版后，仍通过 IndexedDB 恢复逐像素一致的图集。服装原片实际可见，重复进入小屋保留播放器；旧运行时回退和恢复后的走动均经过验证。首次新原片仍需本地准备一次；重开后的缓存画面用于衔接引擎初始化。

## 验收范围

- 519 项前端测试、190 项既有 Node 检查及 4 项新增附件完整性检查通过。
- 56 组实际成长形态与照料用品组合、服装引擎恢复、缓存重开和真实 X11 拖动通过；不更改成长、衣服和已经生效的照料结果。
- Windows 现代 x64、兼容 x64/ia32、Mac arm64/x64 以及 Android 固定签名版本均成功构建和验收。
- 已打包应用实际检查可见原片、桌面/小屋四次往返、拖动、贴边、窗口缩放、衣橱、读书、魔术、课程、留言板、背包、存档重开。
- Windows 完成真实安装、桌面/开始菜单/安装目录入口启动、损坏入口覆盖修复、差量下载与 NSIS 覆盖升级，核对数据保留。
- Android 完成手机/平板交互、Android 15 WebView、悬浮窗及固定签名 APK 覆盖升级；不将模拟器验收冒称华为 Pura 70 Ultra 真机测试。
- Mac 延续原本的本地签名发行方式，首次打开可能仍需按系统提示允许打开。
- 人工注入未缓存图集的解码失败，确认动作可以退出且不会产生额外物品或摩尔豆；正常缓存命中离线播放另行验证。

最终 Release 共 33 个附件。上传后的 GitHub SHA-256 与两份校验清单逐项一致；安卓资源包、资源索引和更新清单同时附在版本页，原安卓更新频道保持可用。后续发版在公开前运行 `verify-release-uploads.cjs` 防止漏传。
