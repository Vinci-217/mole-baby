# 留言保存、素材加载与小屋缩放修复记录

本轮沿用 v0.33.3 私有测试分支。现有存档目录、存档键、成长与衣橱记录保持兼容；没有发布公开 Release 或修改自动更新渠道。

## 留言板

在真实 Electron `file://` 环境复现：编辑框请求 `file:///assets/original/message-board/compose.webp`，返回 `ERR_FILE_NOT_FOUND`。原按钮的 CSS 又设为透明文字、0px 字号，完全依赖背景图里的字，导致按钮空白。

- 编辑框继续使用原 GuestBook 素材，改为应用相对路径的图片；“保存／取消”使用可见 HTML 文字，图片失败也能操作。
- 排查了同类网站根路径：其余 32 个 CSS 背景图路径统一在构建时相对输出样式表解析，兼容原生 file://、网站根目录和子目录部署。生成包中 59 个 CSS 图片引用逐个核对本地文件存在。
- 新增、编辑、回复、标记完成、删除统一处理写入失败。失败不关闭编辑框，不清除文字；按钮显示保存状态，阻止重复提交。
- 原生窗口区分记录冲突、写入失败和超时。冲突时先获取主窗口的最新留言，继续保留当前输入；不会用过期的整份拉姆快照覆盖颜色、成长或衣橱。
- 一条新留言从打开编辑框时就获得固定 ID，超时后重试沿用该 ID，避免延迟确认导致重复留言。

普通新增在修复前的原生 QA 存档中可以成功，不能把所有玩家的保存失败都归为同一个原因。本轮复现了按钮图片路径错误，另外通过拒绝本地写入和模拟记录冲突验证失败恢复路径。

## 素材显示与启动过渡

沿用已完成的 iframe/WASM 复用、两个独立原片播放器的有界复用、原始字节缓存及按当前动作加载完整图集。本轮没有改变原始 SWF、删帧或降低图片质量。

- 原播放器绘制好装扮、形态和颜色后，延后截取一次透明 PNG。进入小屋或试衣间、以及重启后的引擎初始化期间，先显示这张实际原片画面，完整时间轴就绪后替换。
- 缓存键包含原片 SHA256、播放器适配版本、来源、形态、身体注册与颜色；不同颜色和形态不共用截图。
- 内存及独立 IndexedDB 缓存均限制为最多 12 张、8 MiB（保守按字符串内存计数）。缓存位于原应用/浏览器的安全存储区域，不加入宠物存档，不迁移或删除玩家记录。存储不可用时继续从安装包加载原片。
- 小屋被功能面板或游戏遮挡时暂停背后的穿衣播放器，减少争抢绘制资源。

截取画面只用于启动过渡，动画仍播放完整原片。首次使用、缓存被浏览器回收或原片版本改变时，仍需要解释本地 SWF；不能保证所有机器首次打开都瞬间完成。

## 小屋拉姆大小

顶部增加“拉姆大小”。进入调整后拖动四个角等比例缩放，支持键盘箭头微调、恢复默认、取消和完成。调整期间停止走动并保留脚底锚点；名字和按钮保持可读大小。

完成后写入原有偏好键 `ramu-house-preferences-v2` 的可选字段 `roomPetScale`，默认 1，兼容旧记录。不会改变成长、服装或桌面窗口大小。宽屏支持 50%～300%，窄屏按可用宽度限制上限，保证四个触控角留在屏幕内。行走仍限制在中下地面，种子仍不能行走，家具点击优先。

node scripts/loading-save-regression.cjs

专项回归保留在 `scripts/board-scale-regression.cjs`，复用独立 QA 档案；只删除本次脚本自己创建的测试留言，核对之前留言和拉姆身份、颜色、成长、服装均保留。截图及结果在 `artifacts/board-scale-review/`，不把 QA 配置或缓存提交到仓库。私有 Mac 工作流增加此回归，只有实际运行成功才算 Mac 原生验证通过。

## 本地验证结果

- 69 个前端测试文件、500 项测试通过；184 项桌面/更新/打包测试通过；TypeScript 与 `git diff --check` 通过。
- 生产构建完整结束，918 张无损图片逐像素验证，4316 个本地资源约 627.51 MB，包含 567 个原始 SWF。
- 浏览器和 Linux 原生 Electron 两轮实际点击回归通过：留言完整增改回复/完成/删除、拒绝写入时保留内容、重试仅创建一次、保留既有留言和拉姆身份、缩放完成/取消/默认/重启保留，以及手机四角可点击边界。
- 原版装扮截图跨视图首帧：本机多轮浏览器与原生回归约 0.3～0.6 秒（含操作导航等待，不是 SWF 完整就绪耗时）。重启后本地截图缓存可读。不能外推为所有设备的速度保证。
- 四次装扮选择只请求一次 WASM；本机完整原片就绪约 166～963ms，拖动时未出现原片名字占位字段。
- 立即走动打断首次截图后，重新静止可补齐缓存；注入清单失败、WASM 长时间阻塞、丢失启动/就绪消息和启动脚本失败后，重试、迟到就绪恢复与日志导出检查通过。
- 小屋整体界面检查通过：留言、存档身份/备份、背景音乐/随机播放、花海素材、形态、小窗口与损坏存档保护。

Mac/Windows 最终原生打包仍需 GitHub Actions 机器实际运行。本地 Linux 原生测试不等同于 Mac 或手机实机测试；本轮没有宣称完整 Android 原生构建成功。
