# 在 Mac 上使用拉姆

系统要求 macOS 12 或更高版本。在“关于本机”中查看芯片：Apple M 系列选择 arm64，Intel 选择 x64。两种包均为原生架构，不需要 Rosetta。

## 安装和常驻

从 GitHub Release 下载对应 DMG，打开后将“拉姆”拖到 Applications，然后从应用程序启动。也可以解压对应 ZIP，再把“拉姆.app”移到 Applications。

当前提供本地 ad-hoc 签名，尚无 Apple Developer ID 签名及公证。下载后若 Gatekeeper 拦截，先尝试打开应用，再到“系统设置 → 隐私与安全”核对来源并选择“仍要打开”。保留系统安全设置；不需要执行清除隔离标记或关闭 Gatekeeper 的命令。

应用常驻顶部菜单栏，不占 Dock。点击双叶拉姆图标可以显示拉姆、进入小屋、开关散步或退出。关闭、最小化窗口会隐藏，选择“退出拉姆”或 Command+Q 才真正退出。

桌宠跟随桌面空间，也可显示在全屏应用所在空间；小屋只在当前空间显示。实际全屏层叠行为还受 macOS 和全屏应用管理方式影响。支持普通窗口拖拽、拉姆拖动与透明空白处鼠标穿透，不需要屏幕录制或辅助功能权限。文本框支持原生 Command+C/V/X/A/Z 操作。

## 对话和本机数据

照料、商店、五个小游戏、背景音乐、真实时间场景、成长和记忆与 Windows 使用相同代码。DeepSeek Key 在本机主进程保存，系统加密可用时由 macOS 钥匙串支持，不能加密会明确提示。备份中不包含 Key 和个人音频文件。

语音输入使用 macOS 自带听写。在“系统设置 → 键盘”开启听写并配置中文；点击应用的“语音输入”会聚焦输入框，然后使用系统设置中的听写快捷键。文字确认后才发送，应用不会把录音发送给 DeepSeek。系统听写是否离线由设备、语言包和系统设置决定。回复朗读使用本机中文声音。

存档默认在 `~/Library/Application Support/mole-baby`，保留已有旧名称档案的兼容查找。可以用设置中的 JSON 导入导出在 Windows 和 Mac 之间转移宠物与记忆，Key 在各台机器分别填写。

## 开发和验证

在 Mac 安装 Node.js 22 或 24，运行 `npm ci`、`npm run desktop:dev`。`npm run dist:mac` 构建当前架构，`dist:mac:arm64` / `dist:mac:x64` 可指定架构。

CI 使用明确的原生构建机：`macos-15` 为 arm64，`macos-15-intel` 为 x64。每种架构都校验 Mach-O、Info.plist、本地签名、DMG 挂载、ZIP 以及实际 `.app` 的领养、渲染、背包商店、动作、睡眠、背景、拖拽、菜单栏恢复和 Command+V。Key 检查使用隔离模拟钥匙串和虚构 Key，不能替代用户真实钥匙串权限、系统听写准确率或每台机器的安装测试。
