# 布置小屋

进入小屋后点「布置小屋」，打开右侧仓库。

- 已拥有的家具可以重复拖入，或点「放进小屋／再放一件」。同款设计购买解锁一次即可重复摆放；留言板仍从仓库拖出。
- 所有家具都能放在小屋任意位置，包括墙饰和证书，不再划分墙面、地面的可放置区域。
- 点选一件家具后，可拖动本体移动，拖四角等比缩放，也可用「大小」滑条调整。四角和选框按素材可见边界对齐，透明留白不会抢选后面的家具。
- 「复制一件」会保留所选尺寸并增加副本；「收回」只收回当前这一件。「移到前面」可调整遮挡顺序。
- 选中后用方向键微调位置，Shift + 方向键加快移动；Delete 可收回。
- 仓库支持搜索、只看已拥有，并可以收起，让小屋留出更多摆放空间。完成后点「完成」退出布置。

家具位置、大小、副本和顺序自动保存在原存档中。

# 桌面操作

桌面悬停后保留状态、足球、书本和回小屋四个快捷图标。「放大缩小」移到足球的「一起玩耍」菜单中，进入后拖角调整拉姆，完成保存，取消或 Esc 恢复。

点书本开始专注计时，再点可取消。时间显示在拉姆上方，阅读时书本固定、单张纸缓慢翻页；减少动态效果下书本保持静止。时长与正向／倒数计时可在设置中调整，声音和音乐开关也在设置中。

未开启「允许后台播放音乐」时，离开小屋会暂停，再进入小屋从头播放。开启后，桌面与小屋之间连续播放；在小屋里临时关开音乐或普通点击不会使音乐回到开头。
