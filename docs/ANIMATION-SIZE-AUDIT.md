## 本轮修正

1. **18 段元素变身的身体基准。** 以原 SWF 中眼睛所在的身体轮廓测量宽度，排除火焰、树枝、水柱和阴影；分别校准原 SWF 播放和原版图集播放。每段时间轴使用一个固定的等比缩放和注册点，随原来的身体形态调整基准。原图、图集、帧数和动作顺序不变。
2. **大幅道具动作被画布截住。** 扩大透明绘制面，在控制器中反向补偿比例，身体不会随着画布一起放大或缩小。对远距离运动和涂鸦保留单独的固定画布尺寸；最终 16 段涂鸦复查中，采到的身体轨迹均位于画布内。
3. **桌面宿主窗口的裁切。** 将原片绘制范围传给实际 Electron 窗口；道具启动时同步关闭系统的菜单窗口模式。用实际菜单启动涂鸦、结束后恢复装扮，确认屏幕锚点不变，透明窗口恢复原大小。物理屏幕边缘仍会裁切超出屏幕的内容。
4. **短魔法在预加载时播完。** 几何注册后重新准备原片，暂存原本正在播放的子时间轴，等真正展示时再继续，避免在烟雾后露出空白尾帧。原本已经停止的控制帧不会被强行播放。
5. **四段庆典特效误按身体缩放。** 它们没有拉姆本体，改用原动画完整特效范围注册；恢复原始结束帧。另为四种形态共用的短时空魔法记录原始 31 帧结束点。
6. **独立对照页。** 同时显示原形和当前装扮或动作，可以切换九种形态、全部衣服和已接入原片，重播时复用已载入的衣服。此页不打开或改写玩家存档。

原动画中弹簧拉伸、涂鸦变形、飞行移动、元素扩散和火焰长大均保留。自动扫描的“身体宽度异常”可能来自道具遮挡或这些原始形变，已结合画面和源轮廓判断，没有按每帧外包围框反复缩放。
