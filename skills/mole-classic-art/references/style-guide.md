# 从原图提炼的视觉规则

以下结论来自本仓库的实际参考，适用于早期国产 Flash 页游的这组美术，不等于所有年代的《摩尔庄园》都只有这一种画法。风格提炼不要求重复原场景的家具位置、窗户形状或道具内容。

## 形状与线条

树干、桌腿、窗框、木板不是完美对称的几何体：轻微歪斜、端头夸张、长边略弯，形成手工搭建的儿童游戏舞台。大块弧线搭配少量短折角，不能把所有东西都圆成相同的软糖形。

外轮廓比内部结构显著，深棕线条通常比纯黑更温暖。场景有些相邻色面只以颜色交界分开，不需要每块阴影都描黑。木板刻痕、书页、植物叶脉只留一两条概括线。不要使用密集排线、铅笔毛边或整幅磨砂纸纹。

## 色彩与明暗

这组树洞参考的主色是蜂蜜黄、杏色、棕色；户外辅色是清亮黄绿、草绿、青蓝。下面的色值仅是设计起点，不宣称是精确官方调色板：

| 用途 | 建议起点 |
| --- | --- |
| 深轮廓 | `#67452C` |
| 木质基色 / 阴影 / 亮面 | `#DCA05C` / `#A56E35` / `#F1CE70` |
| 草叶基色 / 阴影 / 亮面 | `#87B846` / `#427C38` / `#B5D864` |
| 天光 / 奶白 | `#45BFD9` / `#FFF8D5` |
| UI 橙 / 亮黄 / 白底 | `#FF9E00` / `#FFDA48` / `#FFFFFF` |

材质主要靠两到四块相邻明度表达，亮面和暗面轮廓明确。原道具有少量平滑反光，UI 也有局部渐变，但不能把这些例外扩大成全场景柔焦、漫反射和空气透视。所谓“晨光”应画成窗边一两块淡黄色硬边光斑，而非电影级光束、散景或厚雾。

## 空间与画面密度

场景是轻俯视的舞台，近处台面/地面夸大，窗户和家具允许轻微不一致的透视。用遮挡、前大后小和上下位置区分层次，不追求建筑渲染的单点透视正确性。

桌宠背景要在中央下部安排足够大的浅色地面或桌面，留给原拉姆与气泡。窗、书本、杯子、盆栽集中在侧边与后排，每个都用可读的大剪影；底栏附近不要密集摆物。不要把“丰富”解释成几十件微缩摆件塞满整幅图。

## UI、道具与角色的分工

可以原创面板轮廓、页签、按钮图形和 Logo；先确定同一套橙黄/白/蓝辅助色、线宽层级、圆角比例、选中反馈，再制作一组。普通、悬停、按下状态保持同一轮廓，按下只移动或压缩高光和暗边。标签、数字和交互提示由应用排字，不要求图片模型生成可用文字。

新道具先画一个明确主体，轻微三分之二视角或正面视角，3–5 个主要结构即可；接入库存时不加背景场景。食物、瓶子、玩具可原创，但不要把原名错标到另一件图案上。已有原道具也可以直接复用。

拉姆是身份锚点。现有原图集已经能覆盖待机、走动、互动等动作，应继续使用。若确有新动作需求，必须把对应成长阶段原图作为直接参考：初级无叶、中级两叶、高级扇叶；大眼与身体连接、无常规四肢、身体配色都要按原图，不补鼻口、衣服、毛发或西式大头萌宠结构。新动作不应连带重设全部角色。

## 常见偏离与具体修正

| 偏离 | 修正指令 |
| --- | --- |
| 欧美绘本、水彩纸、刷痕 | 改成干净的 Flash 矢量插画外观，实色填充、清晰硬边、无纸纹。输出仍为 PNG。 |
| 厚木质 UI、皮革、铜钉、立体浮雕 | 换成轻薄白面板与明亮橙黄色圆框，胶囊按钮只留一条高光。木头可属于场景，不统治所有控件。 |
| 3D 塑料渲染、软阴影、景深 | 降低体积，明暗合并为少量硬边色块，删除镜头效果与连续环境光。 |
| 日系/西式 chibi、无关大眼动物 | 删除新角色，保留背景；需要拉姆时使用原图，不让模型临时设计替代物。 |
| 新图像原房间一比一翻印 | 保持线、色、比例和光法，重新安排窗户、书桌与装饰，让内容独立设计。 |
| 家具过小过多、中心挤满 | 合并为少量大物件，把叙事细节移到两侧，扩大中央下部可站立区域。 |

## 当前下一版场景简报

主题：**晨光下的拉姆树洞书桌**。在圆润但不规整的树洞内，一张大号蜂蜜黄木桌延伸到画面前方；左上圆窗透出蓝天和黄绿树冠，右后方放三本略歪的书与一盆宽叶植物。后墙可以有一个不带字的小叶形挂饰。晨光用淡黄色硬边色块表示。桌面中央至下方保持开阔，没有人物、拉姆、动物、文字、按钮或 Logo。

与原图的关系：沿用平面造型、深棕线、硬边局部色、轻俯视和大留白；桌面布局、窗饰和环境内容采用新设计。背景不能提前画好一个假拉姆，真实桌宠由应用独立叠加。
