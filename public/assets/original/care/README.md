# 原拉姆照料与状态动作

原资源为 [官方 lamubone.swf](http://mole.61.com/resource/NPC/lamubone.swf)，SHA-256 `01abf65f3e8db098068a830268bd7a7cefefc1edc93a44565788783d23f8a0cf`。来源与基础成长图集相同。使用 JPEXS Free Flash Decompiler 26.3.0 导出原图；没有重新画身体、叶片、眼睛或道具。

每张图集为 **16 列 × 7 行**，单格 **192 × 208**。各行对应原时间轴标签 `food`、`drenk`（原文件拼写）、`wash`、`medical`、`thirst`、`hungry`、`boring`。三级分别使用原 sprite 936、1532、1777。精确原始动作帧、展开后的主时间轴帧、同一行固定原始视窗、主体范围、位移及缩放均记录在 `source.json` 中。

从展开后的嵌套长动作中实际查看表情和道具，再选取每隔 2 个原始帧的 16 帧短片段。没有把数百帧长动画随意压缩到几个互不相邻的姿势。以基础待机图集的身体宽高和落点校准，每行使用一次固定等比缩放与位移，保留原身体、表情和完整叶片；不逐帧跟踪主体或改变大小。食物和饮水保留近处食盆、奶瓶，远端道具可能超出小桌宠画幅。洗澡、医疗和状态行仅删除与原身体及叶片完全不相连的道具连通分量。与身体或叶片相连的原像素全部保留，包括眼睛、道具遮挡和边缘；远处道具超出画幅时允许裁去远端，避免为了装下完整浴桶、针筒或思想泡泡而把拉姆缩得很小。没有补画、拉伸或重新绘制角色。洗澡取原 `wash` 动作第 174–204 帧连续挤眼、抖干的收尾片段，适合 100px 桌宠视窗，不使用需要很高纵向空间的抛跃入桶片段。桌面播放速度为项目交互适配，并非完整复现原 Flash 运行时。

`*-mask.png` 三个通道分别是原身体 255、204、153 灰阶的覆盖率，保留原嵌套眼白和瞳孔颜色变换。运行时和基础图集一样使用游戏的加法颜色表；叶片、道具及眼白保持原样。探针提取依据 [taomi-codex-pets 的导出方法](https://github.com/mli55/taomi-codex-pets/blob/main/scripts/export-ram-levels.py)，排除原眼白 shape 10、413、422，颜色分离计算同该项目 `compose-selected-actions.py`。图像版权归原游戏权利方。

应用映射：进食用 `food`，饮水用 `drenk`，洗澡用 `wash`，使用药品用 `medical`，饥饿和口渴分别使用原 `hungry` 和 `thirst`；困倦、身体不适及需要清洁时使用低频 `boring` 表情提示。这些是桌面玩法状态映射，未声称 `boring` 是原版疾病或睡眠标签。

原 `boring` 行中并非所有帧都闭眼，因此**睡眠**另外固定使用已有基础图集原 `happy` 的闭眼微笑帧（row 8 / frame 0），叠加很轻的呼吸和 Z 提示。种子使用原 sprite 37 的第 5 帧（图集零基 frame 4）真实闭眼图。没有把睁眼的原 `boring` 帧当成睡觉。减少动态效果时不播放呼吸或帧动画，仍保持闭眼。
