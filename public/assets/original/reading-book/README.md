# 原版紫色书本

素材来自淘米原页游 `root/resource/petcloth/swf2/1200026.swf`，配置名称为 **Ebook**。固定存档与官方资源地址在 2026-11-06 实际请求所得 SWF 的 SHA256 一致，见 source.json。项目衣橱的“魔法书”是此前的本地命名，不作为官方名称。

选取 front book 的 sprite 13，完整导出15帧。只移除 depth 1 的灰色配准占位图形，保留书页矢量、米色纸页、紫色封底、书脊、原配色及帧内矩阵。图集使用共同裁切范围，避免书脊位置随翻页跳变；派生图宽384像素，用于小尺寸显示。

运行时静读使用稳定的展开书页；提取帧中的挠动属于原装扮走动姿态，不直接冒充原版阅读动作。开书、阅读停顿、曲面翻页与有限阅读末尾合书由本地 Canvas 编排；身体仍使用原拉姆绘制组件，阅读时缩小并对齐到书脊后方。种子保留花盆，书放在旁边。不能将这段组合称为客户端完整原版“看书录像”。

复现：

```sh
python3 scripts/art/export-reading-book.py
node scripts/art/pack-reading-book.cjs
```

原件保存在本地素材库，导出另存，未改写原 SWF。权利归原权利方；出处及免责声明见项目 ASSETS.md 和 README。
