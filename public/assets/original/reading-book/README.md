# 原版 Ebook 装扮动画

来源为淘米页游 `resource/petcloth/swf2/1200026.swf`（配置名 Ebook）。官方公开地址与本地固定存档的 SHA256 相同，见 `source.json`。用户参考图中的紫色封底、米色纸页、下垂书脊、神力叶冠和彩色环均在此文件中。

此版本撤掉之前自行编排的开书、曲面翻页与合书，也不再把缩小的另一套拉姆贴到书后面。动画来自原 SWF 的嵌套时间轴：Ruffle 0.7.1 运行原图形和帧脚本，离线适配器按 `ClientAppDLL.swf` 的 `LamuUIManage` 处理形态、方向和骨骼同步。逐帧截取浏览器最终显示，避免直接读模拟器画布时漏掉 Flash 滤镜。每个完整循环都检查了时间轴状态与连续13帧图像重复。

保留原书、身体、眼白、叶冠、彩色环和半透明阴影的相互位置。运行时只做统一裁切、等比例缩放、24 fps 回放与身体换色；没有添加页翻动、开合或身体变形。初级、中级、高级、经典超拉、神力超拉、水、木、火各有自己的完整正面循环。原装扮不支持种子，种子保持花盆。

`*-neutral.png` 是根据原文件黄／蓝／红／粉染色结果归一化的底图，`*-mask.png` 保存身体白、灰、深灰三种覆盖量。使用独立紫色截图检查自调色回放，同时保留眼白、书与叶冠。底图按实际染色结果归一化，以保留最终画面中的眼白、滤镜和透明阴影；原始白色研究截图不直接用于运行时。

这是原素材的独立播放，不是登录原游戏后的录像；不声称已恢复截图所在场景的全部逻辑。工具及研究记录见 `research/original-ebook-capture-2026-11-06.md`。原件不变，派生 PNG 另存；权利归淘米及相应原权利方，参见项目 ASSETS.md 和 README。
