# 拉姆 · mole-baby

一只住在 Windows 或 macOS 桌面的拉姆。可以拖动、摸摸、玩球、喂养，看着它从种子慢慢长大。

[下载 v0.26.1](https://github.com/Vinci-217/mole-baby/releases/tag/v0.26.1) · [构建记录](https://github.com/Vinci-217/mole-baby/actions/workflows/windows-build.yml)

## 小小的桌面陪伴

角色保持约100×108px，鼠标移上来显示 **用品、玩耍、计时、小屋**。背包是 **212×216px** 的小侧窗，4×4正方形格，选择食物、饮品、清洁或药水后，**单击物品即刻使用**，库存和实际数值立即更新；动作继续播放，增益提示缓缓淡出。没有二次确认或等待领取。

![小背包](artifacts/v25-compact-pocket.png)

桌面玩耍只有玩球、摸摸、看蝴蝶和回应心情。状态、成长、装扮、回忆、商店、小游戏、背景与设置都在小屋里。房间和侧窗采用同一套奶油色界面，原角色和物品图形继续保留。

![小屋状态](artifacts/v25-room-profile.png)

## 拖动、四边躲藏与托盘

种子可以手动拖动，不会自行散步；其他清醒形态每12–18秒在最后放置点附近随机移动，活动范围约左右150px、上下100px，每步约28–64px，避免跑遍屏幕。用户拖动会重设活动中心。

拖到工作区任一边缘，松手后立即开始收进去：种子小跳、初中级迈步、高级与神力飞入。鼠标移上只探头，拖出来才完整出来。随机探头仍为2–5分钟一次。拖动使用系统光标坐标；原生窗口被Windows限制位置时，用内部偏移保持宠物贴边，避免上下拖动累计漂移。小窗开关不改变宠物的屏幕位置。

右下角托盘（Mac菜单栏）可开关 **拉姆置顶**、**鼠标穿透**、散步和躲藏。开启穿透后，连宠物本体也不拦截点击；从托盘取消即可继续互动。透明空白区域仍自动穿透。关闭窗口默认收进托盘，托盘「退出拉姆」才退出。

## 音效与本地回忆

吃东西的吧唧、喝水的咕嘟、洗净提示、灵光和玩球蹦跳为本机合成短音效，不是背景音乐或官方录音。小屋设置有独立的「互动音效」开关、音量和五种试听；BGM仍单独控制。参见 [音效试听](artifacts/v25-interaction-sounds.wav)。

**已移除自由对话、语音输入、朗读及API配置和联网服务。** 升级会删除旧API凭据和聊天记录；保留宠物成长、用品、装扮及真实照料回忆。拉姆仍会偶尔出现简短的生活提示和状态气泡，可以关闭主动陪伴，不会打开麦克风或调用对话API。

四种颜色、五个成长阶段和四种最高形态保留；9件装扮使用原服饰素材并按阶段适配。小屋里的商店用摩尔豆购买用品，小游戏奖励和慢成长规则继续保留。角色与服饰来源见 [ASSETS.md](ASSETS.md) 和 [装扮说明](docs/WARDROBE.md)。

## 拉姆自己的小日子

小屋每日签到可领取1000摩尔豆。拉姆会自己翻书、玩球、顶书练平衡，中级以后还会练习魔法变装；出游有归期，可以随时叫回来，经历会进入回忆。自然活动与出游均可在设置关闭，专注计时和安静偏好优先。

## 安装

Windows运行 `mole-baby-0.26.1-Setup.exe`，或完整解压ZIP后打开「拉姆.exe」。Mac选择M系列的arm64或Intel的x64版本，将应用拖入Applications；最低macOS12。Apple签名与公证状态见发布页顶部，首次打开说明见 [Mac使用指引](docs/MACOS.md)，安装盘及发布附件也提供独立HTML说明。无需关闭系统安全保护。
