# 用品动作：原始身体与物品适配

这版为目录内全部 28 种用品提供独立的动作配方，记录在 `src/item-motion.ts`。这些是项目对原版素材的动作适配，**不是 28 段官方逐品专属动画**。主体始终使用原页游角色图片，用品使用原道具 PNG；新生成的插图只有一把辅助牙刷。

## 原始角色与道具

- 原角色文件：`http://mole.61.com/resource/NPC/lamubone.swf`。
- SHA-256：`01abf65f3e8db098068a830268bd7a7cefefc1edc93a44565788783d23f8a0cf`。
- JPEXS Free Flash Decompiler 26.3.0 导出 `food`、`drenk`、`wash`、`medical` 原时间轴。三种成长形态分别为 sprite 936、1532、1777，配方使用每行动作原 16 个采样帧。
- `public/assets/original/item-motion/*-neutral.png` 和 `*-mask.png` 是 192×208 单元、16 列、4 行的身体图集。每行沿用 v0.5.0 的固定身体视口、比例、注册点；不根据大浴盆或饮料重新缩小角色。
- 原吃饭动作固定带粉色食物和金色食盆、喝水动作固定带奶瓶。v0.6.0 从 SWF 显示列表中移除这些道具，保留原 `petBody` / `peBody`、叶片及嘴部，再叠加实际消耗的物品。清洁、药水也移除不对应用品的毛巾和针筒。没有重画角色或用滤镜改动叶片、眼睛和花盆。
- 暖色木浴盆是原 SWF 的 shape 205；源 PNG 导出为 `bath-tub.png`。
- 28 种用品图片来源仍见 `public/assets/original/items/sources.json`，不以表情符号替代实物图标。
- `toothbrush-generated.png` 是专为此项目用图片模型生成的透明辅助道具。原 `180024` 图标只有牙膏管，不能拿牙膏管本身来回擦脸冒充刷牙。该牙刷不是官方素材。使用提示为：早期国产 Flash 页游物品画风、薄荷色侧面小牙刷、暖深色描边、白刷毛和少量牙膏、无文字无角色、透明背景。保留原始生成文件，不用 SVG 绘制牙刷。

更完整的来源、原帧编号、视口及导出文件哈希见同目录 `sources.json`。

## 播放约束与验证

- 每种用品的身体与道具由同一 `requestAnimationFrame` 已用时间驱动。React 的普通状态刷新不会从第一帧重新播放；相同物品再次使用以 `actionId` 开启新的有限动作。
- 动作范围 1.8～3.6 秒；完成时身体和道具同时结束。原种子只改变独立身体层，原花盆始终不旋转、不移动。
- 道具注册到各原帧的嘴部位置，尤其初级拉姆原吃饭动作会左右转头；固定把所有图标贴在角色中心会遮眼或浮空。
- `prefers-reduced-motion` 保留实际用品、牙刷、浴盆等静态识别特征，并仍在正常时长后结束。
- 原图的四种加色蒙版保持不变：身体配色变化，叶片、眼睛、盆和道具不染色。
- 单测覆盖目录与源 ID、有限结束边界、三成长形态与种子帧范围、刷牙短刷、浴盆与洗脸区别、不同饮用方式、减少动态效果下的稳定特征。
- 已在真实浏览器以 100px 拉姆检查全用品，并校准食物的嘴部注册点；没有通过缩小身体来挤进大型道具。
