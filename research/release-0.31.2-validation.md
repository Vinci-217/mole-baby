# v0.31.2 Windows路径修正与发布验证

日期：2026-10-29（北京时间）。本版包含全部 v0.31 功能与预览，不改动玩法和原动作帧。

## 为什么使用修正版号

v0.31.0 标签的 Windows 三路打包成功，但在公开发布前被 ZIP 完整性检查拦截：新增图集使单个 `resources/app.asar` 超过旧的512MiB单文件上限。该标签没有公开 Release，没有进入 latest 更新渠道，也没有覆盖标签。

[首次构建及拦截结果](https://github.com/Vinci-217/mole-baby/actions/runs/40787876786) · [此前全部功能的本地验收](release-0.31.0-validation.md)

## 修正与本地验证

- 使用 Electron 标准 `asarUnpack`，将 `uploaded-actions` 与 `daily-frames` 两组大图集独立存储，虚拟 ASAR 路径保持相同。其余代码和既有素材继续打包。
- 保留原512MiB单文件上限、2GiB总展开上限、CRC、文件清单、SHA和原生应用检查，没有通过关闭或放宽校验来发布。
- 真实 Linux 目录包的核心ASAR为106,612,229字节（约102MiB），1635个外置资源共463,921,585字节。逐个与实际构建目录核对散列，全部一致。
- 新打包核验检查每个资源的ASAR虚拟入口、unpacked标记、物理文件及SHA，拒绝重新塞回核心包、漏文件或被篡改的资源；已接入Windows和Mac打包验收。
- 374个Vitest与121个Node测试通过，包括新增的外置资源、篡改和错误打包回归。
- 启动实际打包可执行文件后，通过原片完整播放、四形态、自调药水、角色位置扩展/恢复、取消、超时及后续动作无错误奖励检查。不是仅用开发服务器或源码版Electron替代打包验证。

## 正式平台与公开下载

Windows现代64位、兼容64/32位、Mac Apple/Intel五路必须全部打包和原生验收通过，才能公开新Release。最终流水线回执、下载SHA及更新元数据核对结果在发布完成后追加。

更新仍需确认。当前Mac本地签名版通过SHA校验后打开DMG，由用户替换应用；原生Mac验证会通过真实GitHub下载并只读挂载核对版本，不声称绕过Apple验证或静默升级。

后续结果：Windows检查发现新校验器传给ASAR API的路径使用了URL分隔符，原生Windows API需要本机分隔符；v0.31.1被测试拦截，未公开。本版已对ASAR查询路径应用本机规范化，资源URL和运行时路径不变。
