# v0.31.7 发布验证

用户明确要求完善未来增量／差量策略、小屋窗口自定义大小、背包分类平行排列，并在修复后重新发版。本轮已授权正式发布。

## 改动

更新器共用内容差异计划：支持新增、删除、移动与修改，合并间隔不超过 64 KiB 的下载段。变化达到 90%、超过 512 个请求或计入请求开销后接近全量时选择完整包；异常仍验证并回退。设置新增持久化的「自动选择／完整包」，完整模式绕过差量索引及分段请求，偏好不授予下载／安装许可，传输期间拒绝改动。

Windows 继续使用 electron-updater 6.8.11 的真实 SHA512 下载／NSIS 验证与安装流程，只替换传输计划；本地签名 Mac DMG 共用规划并核对完整 SHA256。标准签名 Mac 的 ZIP 继续使用上游原生差量及完整回退。

小屋新增八方向边缘拖动与键盘调整，使用原生 DIP 指针和初始窗口边界计算，防止累积漂移；保留 Windows 固定无边框样式与软件合成。正常最小尺寸 800×640，工作区、全屏、托盘与桌面切换均受保护，窗口尺寸持久化。背包改成四个横排分类，同时保持 212×216 小窗与 4×4 方格。[真实截图及交互说明](../docs/ROOM-RESIZE-AND-POCKET.md)。

## 候选构建调整

v0.31.6 候选（`96db0dd4baf605a0f94a95420b0d68de3e641830`）在正式原生测试时被阻断，未创建公开 Release，latest 继续为 v0.31.5。Windows 鼠标测试反复启动 PowerShell／C# 编译，发生 20 秒超时；Mac 缩放测试对固定增高量的断言没有考虑工作区限制。测试工具现改为一次编译原生光标小程序，并根据真实工作区验证缩放边界，保留所有尺寸、保存、全屏与桌面还原断言。应用功能逻辑未因这些测试调整而改变。v0.31.7 以新标签重新完整验收，未改写失败候选标签。[失败候选记录](release-0.31.7-candidate-checks.json)。
