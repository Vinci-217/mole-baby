## 动作

- 神力超拉的原帧摸摸方案改用正常的21帧正面悬浮，不再用86帧大笑。整体位置抵消源镜头位移，只保留不到1px的小幅浮动；嘴和眼睛为原帧，不叠画大嘴。应用内四种最高形态也减小摸摸角度、平移和形变。
- 初级与中级原帧拖拽预览去掉垂直抬升、松手上下弹跳，抓取点锁定身体上沿。应用内对应形态去掉拖拽的垂直惯性、垂直缩放和额外抬升，保留水平跟随和叶片反应；正常自主散步、侧边走入不受影响。
- 睡觉先进行一次2.4秒的张嘴打哈欠，再闭口，转入缓慢呼吸和原素材Z字上浮。所有五阶段、四种最高形态、四种颜色均适配；种子只改变脸部，花盆不歪斜、不移动。减少动态效果时直接采用闭眼静态姿态。
- 哈欠用原素材的闭眼形状35/1726与嘴743重新编排，嘴最大宽度约为眼部跨度的13%；这是桌宠睡前适配，不称作完整官方睡眠动画。嘴的帧序列与原有呼吸分开，避免睡着以后持续打哈欠。
- 哈欠服饰沿用对应形态原闭眼姿态的定位，避免加一个动作就丢失装扮或错位。

原角色和素材来源、SHA256见 [原帧研究](v30-motion-previews.md)、[角色来源](../public/assets/classic/SOURCE-RECORD.md)及 [哈欠素材记录](../public/assets/original/yawn/source.json)。足球素材与播放代码保持不变。

## 气泡与原生标题

小屋说话气泡改为显示在完整角色视口上方，并留出手掌/叶片空间。到期后直接卸载元素，修复原来的「隐藏气泡 + disabled按钮默认半透明」残留。取消小屋底部重复浮框；背包/商店等必要操作结果放在面板内，签到结果使用角色气泡。

原生BrowserWindow标题为空，并拦截网页标题回写，避免「拉姆」文本再次进入透明窗口标题。Windows从创建起固定不可由系统边框缩放，保留frame:false和thickFrame:false；小屋/背包的程序化切换尺寸继续有效。应用名称、托盘菜单与小屋标题仍叫「拉姆」。没有系统悬浮tooltip。

五阶段气泡的位置、到期移除、底部无重复浮框已在真实浏览器测试。Windows配置、页面标题回写和模式切换由原生生命周期测试覆盖；当前云主机是Linux，不能把配置测试当作已经完成Windows实机复现。Windows原生标题位测试入口仍为 `scripts/windows-window-chrome.cjs`。

## README动作目录

README包含新原帧交互方案和实际应用动作目录，两者明确区分。实际应用目录复用Ram组件、CSS、道具与服饰，不用另一套绘制假装运行效果。覆盖移动/张望、睡眠/醒来、摸摸/看书/追蝶、四种心情/眩晕、六种异常状态、独处/玩球/练平衡/变装、四边躲藏探头、全部消耗用品、九件装扮、最高四形态与四色。

四边GIF只展示渲染层的走入、隐藏与探头，不代替Windows/macOS屏幕边缘的原生窗口测试。出游的倒计时与文字回忆没有另造「拉姆离开桌面远行」的官方角色动画。

别名共用动作：waiting/still为安静陪伴；running-left/right与walk-left/right共用方向帧；play-alone与play共用足球；read-alone与focus共用翻书；feed/eat及具体食物、drink及具体饮品、wash及具体清洁、medical/use及具体药水按统一照料类别播放，区别为真实用品图与配色。README展示全部用品，避免把同类换图误称为独立官方动作。

复现：

```sh
node scripts/record-source-motion-preview.cjs
node scripts/record-animation-gallery.cjs
node scripts/speech-layout-regression.cjs
npm test
npm run build
```

录制为24fps，固定浏览器事件时钟并采集真实渲染帧；帧数、尺寸、阶段与物品配置、浏览器错误记录在 [checks.json](../artifacts/animation-gallery/checks.json)。原始PNG帧未提交，GIF放在README中方便审阅。

本轮通过223项Vitest与54项Node测试，生产构建通过。浏览器补充验证32种形态/颜色组合的睡眠、原Z字上浮、正常眼睛的摸摸、足球原帧时间轴、拖动不重启动作与减少动态效果；种子/初级/中级/神力超拉在实际应用中均由原动作结束回调恢复陪伴。气泡在五阶段均不遮挡角色，到期后元素数量归零。隔离Linux桌面中的生产Electron也验证了网页标题写入及三次小屋/背包切换后原生标题仍为空，打包内的哈欠资源正常播放后转入睡眠；这不能代替Windows实机验证。Windows/macOS原生安装包与发版流程本轮未运行。
