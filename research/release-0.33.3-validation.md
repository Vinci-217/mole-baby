## Windows 启动入口修复

用户反馈 0.33.2 安装后，桌面快捷方式提示找不到执行程序。Windows 专项检查对公开的 v0.33.2 安装包进行了复现：在含中文和空格的安装路径中，原安装包的主程序存在，且快捷方式实际可以启动；检测时曾把 Shell Link 的路径读取方式误判为空，随后改用 Windows 原生 Unicode `IShellLinkW` 接口复核。

0.33.3 的安装器加强了入口管理：安装完成后检查最终安装目录中的主程序，按实际位置重建安装目录、开始菜单和现有桌面入口；安装目录内额外提供「拉姆.lnk」和主程序。快捷方式的目标、工作目录和图标均指向同一套成品。主程序仍是「拉姆.exe」，应用 ID、存档目录和更新渠道保持不变。

Windows 专项测试先直接点击三个入口并确认出现安装目录中的应用窗口，然后故意把三个入口改到不存在的程序，再用同一安装包覆盖安装，确认三个入口都恢复。测试覆盖桌面、开始菜单、安装目录、中文路径、空格路径和现代 Windows。正式六平台流水线中的 Windows 现代版和两个兼容版也通过了完整应用启动、动画资源、安装器和升级存档检查。

如果用户仍看到旧快捷方式错误，直接运行 v0.33.3 对应的 `Setup.exe` 覆盖安装即可，无需先卸载，也不要删除存档。安装目录中的「拉姆.exe」可以作为临时启动入口；若主程序本身不存在，应检查 Windows 安全中心保护历史记录并重新下载官方安装包。
