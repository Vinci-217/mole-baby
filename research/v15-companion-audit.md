# v0.15 桌面拉姆陪伴复核

核对日期：2026-10-20。实际阅读原 `ram-level-animation-sources.json`、神力图集记录、原 `petfood.xml`、场景音乐映射及既有导出说明；实际查看小屋、橙白原宠物面板、熊熊饼干、原中级角色与初级原动作图集。没有声称看过未取得的原游戏视频。本轮不重画拉姆，不提高成长速度，不增加领养颜色，不把新增蝴蝶互动声称为原游戏原动作。

## 发现与修改

| 范围 | 发现 | 本轮结果 |
| --- | --- | --- |
| 照料声音 | 动作一开始只播放一段泛化吃/喝/洗声音，和用品的实际拍点不同 | `itemSoundScore` 从每款物品的入场、活跃段和节拍计算接触时间；由实际原图播放的 RAF 时钟触发，只发当下拍点，不提前排整段音频 |
| 生活拟声 | 刷牙、水流、泡泡、脆食、软食声音不分，翻书/玩球也没有接触声 | 区分12类短拟声；翻书在8秒周期的翻页段轻响，球在两次触碰时响；减少动态效果时没有翻页声 |
| 游戏反馈 | 成功配对、接住或采果的画面缺少即时声音 | 仅成功/有效操作出声，不在错过时惩罚性叫喊，计分、碰撞和奖励规则不变 |
| 桌面小日常 | 静止之外主要靠周期性暖心文字 | 加入有限的轻微张望与小蝴蝶；只动原角色层及道具，不移窗口，种子盆单独固定，飞行形态保持原 row0 和悬浮层 |
| 陪伴分寸 | 新小动作与原说话计时互相重置，可能使主动说话一直延后 | 把说话截止时间保存在 ref 中，短暂动作只阻止当下发送，不丢失已经安排的间隔；允许下一次15秒检查再发送 |
| 情绪 | “不开心”可走开心分支，“没完成”可触发庆祝，状态把“不累/没有压力”当成低落 | 共同使用 `companionFeeling`，覆盖常见明确否定；这是本地规则，不声称理解全部自然语言或作诊断 |
| 身份与回忆 | 首次领养说好久不见，聊天回复会自动出现摸头手势 | 初次见面用初次招呼，重开按本机时段与状态问候；聊天只轻轻张望。食物回忆严格匹配真实喂食事件与目录，删除后即消失 |
| 偏好 | 聊天里的“不要讲鸡汤”没有进入 boundary 的提取规则 | 补上鸡汤/说教/大道理，实际保存并用于过滤，不制造新的用户偏好 |
| 小窗 | 玩耍纵向排列，新增互动后会更长 | 两列卡片，用原图标和新蝴蝶道具，保持14px主标签；实际原生窗口另检查无纵向滚动 |

## 自然动作约束

默认每2–4分钟一次短张望，每第四次改为6.5秒看蝴蝶；初次不会立即启动。动画期间、照料中、开面板、对话/语音、睡眠、低健康/低精力/饥渴、侧边躲藏和散步时不启动；手动专注、安静模式与用户保存的安静边界同样阻止自动动作。隐藏页面不触发，恢复至少留15秒，不连续补播。设置可关闭，偏好保存在既有偏好键，音量默认45%。这些被动动作不添加共同事件、不刷关系、不改变库存/成长/坐标。只有明确邀请看蝴蝶才作为实际共同玩耍记录。

## 画法与来源

1. 轮廓沿原小屋的暖深棕局部勾线，保留圆弧与短折线。
2. 剪影参照原饼干的小图标清晰度，蝴蝶只保留四翼、短身体、双触角。
3. 色面为黄、橙、棕三组，原身体、眼白、叶片、头冠和花盆不被替换。
4. 高光是短奶白色块；生成图有轻微色面过渡，缩到实际小尺寸后接受，不描述为逐像素复制。
5. 道具在原角色头部附近小范围飞行，给气泡、工具栏留白。飞行层造成的边界偏移已按实际32组合画面复核并降低道具位置。

完整图片提示词与校验值见 `public/assets/generated/v15-butterfly-provenance.json`。程序只移动该图片并改变横向缩放表现扇翼，不用程序绘制新角色。音效仍为本机程序合成，沿用此前未找到可靠原叫声的证据，不冒充原录音。12首原场景 BGM 字节保持不变。
