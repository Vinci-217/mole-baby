# 免费原片互动、原版装扮与 Android 差量更新

本轮仅本地预览，未提交、推送、打标签或修改更新渠道。

## 行为

- 足球里的互动面板改为“道具 / 魔法”图标网格；11 种玩耍道具直接使用，不购买、不扣摩尔豆、不消耗历史库存。食品和照料用品沿用原规则。
- 7 组魔法按行为合并不同成长阶段的重复版本；另接入已取得的变身和技能原片。神力形态缺少某段原片时可临时播放素材自带的形态，存档的成长、衣服与颜色不变。
- 21 种课堂角色动作作为自然动作候选，不添加解释页。课堂界面、证书、场景和图标不作为拉姆的身体动画。
- 全部 122 件衣服，包括原有 12 件，统一使用已核对来源和 SHA-256 的官方 SWF；普通活动不再用手工衣服贴层。旧衣服 ID、购买记录、价格和所有权不迁移。
- 当前阶段有原片就用当前阶段；没有就回退该衣服的初级原片及其走法。脱下后恢复实际成长阶段。种子期拒绝穿戴，切回种子会脱下衣服但保留衣橱。
- 播放器按原身体骨骼定位；特殊整体变身按原片的命名身体或完整角色定位。按真实成长形态的身体宽度保持大小，不让大帽子、翅膀的外围边界改变身体缩放。方向切换复用定位。
- 同一衣橱播放器与 iframe 在换装时复用；加载消息有序号，旧请求不会冒充新装扮已加载。

## 包体和加载

567 份原 SWF 保留在安装资源中。构建跳过已由 SWF 替代的重复动作图集和旧衣服拼接图集，只处理构建目录，不删除 `public/` 或 `local-assets/`。

网页资源构建约 643 MiB → 285 MiB。此数字是 `dist` 目录，不是完整桌面安装包或 APK。901 张仍使用的 PNG 采用无损 WebP，并逐像素验证可见 RGBA 与全部 alpha 一致。重复构建通过源文件与产物 SHA-256 验证缓存。

Android 中 JS / HTML / CSS / WASM 仍随 APK；SWF 作为原片资源进入素材包。调整 APK 的播放器代码仍需安装新 APK，不能由旧版纯素材更新替换。

## 差量更新

差量计划开始后始终使用 HTTP Range。每段最多三次失败尝试，断流后从已收字节继续请求剩余部分。分段不受支持、旧基线损坏或校验失败时停止并保留原版本；不请求完整包。索引获取失败明确报错，不默默当成全量。

保留至少一段可复用数据时，不因旧的 90% 阈值、请求数量或小段合并而改选全量。没有可用基线、完全没有可复用分块，或用户主动选择全量时，才在开始传输前选择完整包。

## 存档与验证

保存键、用户数据目录、人物身份、颜色和回忆的持久化方式未改。本地预览使用 `npm run build:preview`，明确保留本地调试入口；正式 `npm run build` 仍默认关闭调试。此前调试存档恢复问题按用户要求本轮不重做。

浏览器回归复用 `artifacts/native-outfits-review/browser-profile` 和 `mobile-profile`，只在不存在记录时初始化独立测试档；已有记录不清空。保存 before / after / retained-record 快照，测试中的换形态通过界面操作完成。测试档不是用户本人浏览器里的存档。

验证入口：

- `npm test`：游戏规则与桌面回归。
- `node scripts/android/test-transport.cjs`：直接编译生产差量代码，覆盖断流重试、206 实际 HTTP 重建、不支持 Range、基线损坏、取消、哈希校验和旧存档保留。使用校验哈希的 JUnit / JSON 测试依赖，无需 Android SDK。
- `node scripts/review-native-outfits.cjs`：同档重开、免费道具、魔法、衣橱 iframe 复用、方向切换缩放、种子期脱衣、成长和旧回忆保留。
- `node scripts/review-native-mobile.cjs`：沿用测试记录的 Android 桥接模拟，检查 320 / 393 宽度、免费互动、魔法、素材加载和重开保存。
- `node scripts/audit-native-outfits.cjs`：全部 122 件原片加载和身体定位。
- `node scripts/record-native-clothes.cjs`：录制实际原 SWF 播放器的站立、左走、右走；仅增加说明文字与画布背景，不合成或绘制服装。

Android SDK 在本环境缺失，安装尝试因磁盘空间不足中止。已执行 JVM 下载测试和手机浏览器模拟；本轮没有构建 APK，也未在华为真机上验证更新安装。

## 本轮最终结果

- TypeScript 检查通过；454 项 Vitest、162 项 Node 回归、17 项 JVM 差量测试通过。
- 122 件原版装扮逐件加载、定位全部通过；5 件特殊变身装通过原命名身体或整体角色定位。
- 同一个持久化测试档连续重开通过，旧颜色、库存、衣橱、自然成长、摩尔豆和旧回忆保留。
- Android 桥接模拟在 320 / 393 宽度通过，无缺失图片或横向溢出；原片播放通过。
- Android 素材包生成通过，3356 项素材，226 MiB；567 份原片加 1 份控制器，两个 WASM 随 APK，许可证保留；ZIP 全部条目 CRC 校验通过。打包临时输出已删除以释放云电脑空间，校验回执保存在 `artifacts/native-outfits-review/android-pack-checks.json`。
- 连续验证期间发现静态缩略图加载全部照料图集，现改为按需加载，原片与染色缓存数量设上限。云电脑磁盘不足曾导致 Chromium 页面退出；释放本轮打包临时输出后，同一个浏览器测试档完整回归通过。
- 网页资源 `dist` 约 285 MiB，省略 1125 个被原 SWF 替代的重复图集文件；原始素材文件保持不变。
