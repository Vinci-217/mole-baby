# 本地预览 · 自由家具布局与阅读计时

本轮按用户反馈继续修改，保留 preview/mobile-room-board-layout 分支及既有未提交修改；没有 commit、push、版本标签或发版操作。

## 最终行为

- 桌面快捷栏回到状态、足球、书本、回小屋四个小图标。大小入口移入「一起玩耍」前两排；出门使用路径／目的地 SVG 图标。玩耍菜单移除音效开关，设置中的互动声音、游戏音效和 BGM 开关保留。不支持原生缩放的 Android 悬浮宿主不显示电脑端的大小操作。
- 时间单独显示在拉姆本体上方，计时按钮始终显示原版书本图标。计时期间隐藏同位置气泡，避免互相遮挡。
- 阅读保留原版拉姆本体，不再给整个身体施加倾斜／拉伸。沿用现有打开的书本道具，纸页绕书脊翻动：约5.5秒阅读、1.5秒翻页，再停顿。纸页由 Canvas 本地绘制，属于本地适配，不宣称取自官方完整阅读动画。减少动态效果时保持静止，翻页音效服从互动音效开关。
- 家具默认尺寸基准缩小32%，各件保持图片宽高比。所有类型、所有背景下均可在小屋任意位置摆放，显示时保持在画布内。购买解锁同款设计一次后可重复摆放，不额外扣款；每件有自己的实例键、位置、大小和叠放顺序。
- 选中一件后可拖本体移动、拖四角等比缩放（25%–300%）、滑条调整、恢复默认、复制、移到前面、收回。删除／缩放只作用于所选副本。方向键微调，Shift 加速，Delete 收回。
- 原图透明区域自动计算紧贴可见像素的矩形，32×32 alpha 采样参与前后层的点击选取，透明留白不抢选下面的物品。阻止浏览器随后对上层矩形按钮的默认聚焦，保证 alpha 选择结果不被覆盖。设置面板按实际尺寸避开所选物品和缩放角；仓库支持搜索、已拥有筛选与收起。
- 未开后台播放时，离开小屋暂停，回小屋从0秒开始；开启后台播放时连续播放。在小屋里普通点击、短暂关开音乐仍保留进度。

## 数据兼容

原 room.owned、room.placed、id/x/y 仍有效，不将旧家具强制转换或重新购买。新副本增加可选 instanceId、scale、order，保存导入时按实例键去重，保留同类型的不同副本。原存档目录、ramu-house-save-v1、身份创建时间及回忆关联不变，未新增第二份存档来源。

新测试用实际 UI 保存和导入，验证身份、紫色、原物品、旧留言不被布局修改或重载覆盖。Android 旧脚本曾直接在 live renderer 背后改 localStorage 后重载，这会被正常的 pagehide 快照覆盖；本轮改成走公开的 JSON 导入流程，再验证解锁与重载，未修改养成解锁规则来适配测试。
