# v0.31 原动作与换色调研

记录日期：2026-10-29（北京时间）。延续 `research/original-room-handoff.md` 的交接实现，本轮用户明确要求完成测试后发布 v0.31.0。

## 上传的原片

用户提供的《拉姆动作swf合集.zip》含 247 个 SWF，SHA-256 去重后为 238 个文件，共 47,204 个时间帧。原件、中文归档路径及散列见 [来源清单](references/uploaded-lamu-actions/sources.json)。四组分别为初级、中级、高级和经典三片金叶超级拉姆；最后一组不能冒称水、火、木或神力超级拉姆的专用动作，也没有种子期原片。

用品按原 `petfood.xml` 的名称、分类和效果绑定：食物、饮品、清洁和药水从背包单击使用；新增缺少的用品及原图标。原文件的活动赠品价格为零时使用明确标注的桌宠商店价格。足球、三种逗逗、弹簧、乐刷刷和四种涂鸦进入桌面及小屋的“一起玩耍”。每个文件都能对应到用品或玩耍入口，没有仅放进目录而无法使用的孤立动作。各形态没有的文件不伪造为原片，继续使用已有兼容动作。

转换不执行 SWF 的 ActionScript：解析时间轴，将完整身体、眼睛、叶片和道具一起栅格化。不能只取根时间轴第一帧（这些根大多只有一帧），必须采样内部动作时间轴。中级 180060 的身体实例没有名字，单独记录了推断的绑定。九个相同文件共用纹理，仍保留各自的用品编号。

每段固定相机与缩放，24fps 按 `frameMap` 播放；不逐帧自动适配角色大小。稀疏组件裁切打包到不超过 2048×2048 的纹理页。组件外接矩形可能交叠，绘制必须在限定矩形内用 copy 覆盖，不能 alpha-over 叠出不透明轮廓。中性色纹理允许最多一个 RGB 量级的压缩差，身体遮罩及整帧透明度保持无损；运行时从遮罩还原精确透明度。952 张源整帧透明度抽样重建通过校验，压缩记录和 SHA 一起保留。

原片带自己的完整变形，播放期间不硬贴当前装扮。完成或取消后恢复已经穿戴的装扮，所有权和存档不变。种子、水火木和神力形态继续使用已适配的用品动作。此限制是原片覆盖范围，不能宣称本轮新增了九形态全部原版专用服装动画。

玩耍完整播放后心情最多增加 6、精力消耗 3，只结算一次；中途取消、切换场景或播放失败不发完成奖励。照料仍在单击时扣除一个实际库存并增加状态，末尾显示实际增量。点击不增加成长值。ESC、摸摸或打开其他界面可以中断动作。切回基础窗口时保持原宠物坐标。

## 日常动作

删除“顶书练习”。摸摸、看书、睡眠、追蝴蝶、张望、醒来和眩晕使用九形态共 63 组完整帧序列。它们是现有原身体图层、既有位图道具和已有编排在离线浏览器中以 24fps 合成的姿态，**不是新发现的官方整段 SWF，也不是数千张新手绘**。不穿装扮时播放整帧图集；穿装扮保留已有身体与衣服接点的同步方案，避免把帽子固定在整段动作外侧。

高级八叶冠使用原图层离线投影出 40 个旋转姿态，按转速选择帧；保留原身体的完整时间帧。40 个角度采样是图层适配，不称作 40 张官方新绘关键帧。单页尺寸仍在 2048 内。隐藏窗口停止帧刷新；有限动作有独立完成计时，不因浏览器暂停 rAF 而一直卡住。

原件约 5MB，只在研究目录保存，不打入安装包。完整栅格动画约 448MiB，另有既有素材；这次素材覆盖明显增加，不能声称安装包变小。已去重重复 SWF、裁掉空白、按页压缩并限制解码缓存；只加载当前动作，不启动时解码全部图库。预览 GIF 在 docs 中，也不进客户端。

## 调色玩法证据

原客户端的 [AladdinView.as](references/color-mixing/AladdinView.as) 指向 `module/colorEditor/colorEditor.swf`，其 [colorEditorView.as](references/color-mixing/colorEditorView.as) 使用红绿蓝三瓶、每次 25.5 的 RGB 分量及调色锅。该原玩法改变的是**摩尔玩家颜色**，并非拉姆换色药水背包。

当前环境访问官网 HTTP 和 HTTPS 均被拒绝，未声称从官网成功下载。通过固定版本的社区资源归档取得相同模块：[Miigon/RecMoleRes 7a6d6b3](https://github.com/Miigon/RecMoleRes/tree/7a6d6b3c7037a85afb28ad6abd4d7f4adfddb5ff/root/module/colorEditor)。请求结果和散列见 [下载记录](references/color-mixing/fetch-receipt.json)，SWF SHA-256 为 `b42c6e29f5f30d2f9aae412c604fd4ba2de738e830e66b8c4a6f844d696a3ebc`。原锅、色瓶和水面遮罩导出到 `public/assets/original/color-mixer/`，来源见该目录 `sources.json`。不能把社区存档称为官方网盘。

新流程为本项目适配：小屋游戏 → 拉姆换色游戏 → 点击/拖动 RGB 瓶或滑块/拾色器 → 实时试色 → 装瓶 1.2 秒 → 药水背包 → 单击使用。每次瓶增量取整为 26；RGB 范围 0–255，支持黑、白和自定义六位十六进制色。

装瓶不直接改色，也不奖励摩尔豆或成长；相同颜色叠加，一个存档最多保有 32 种自调药水，每种最多 9999。未完成装瓶就关闭不发物品。双击装瓶只完成一次。自调药水不能从商店接口免费买入。稳定 `mix-rrggbb` 编号通过严格校验，继续兼容 v1 存档和四种基础色；领养仍只有原四种颜色。身体遮罩改变身体色，眼白、叶冠、花盆和道具不跟着染色。自调色随正常成长、手动阶段切换、重启和备份继续保存。

## 复现入口

- `scripts/art/UploadedSwfExporter.java`、`export-uploaded-lamu.py`：完整原片与身体遮罩导出、去重和打包。
- `scripts/art/reference-uploaded-alpha.py`、`scripts/verify-uploaded-atlases.cjs`：原始栅格与播放图集透明度核验。
- `scripts/record-daily-frames.cjs`、`scripts/art/pack-daily-frames.py`：实际组件合成、颜色探针、完整日常帧序列。
- `scripts/art/preview-v31-frames.py`：从实际帧表生成完整 GIF；延时按 GIF 的 10ms 精度量化，不冒称新绘姿态。
- `scripts/v31-regression.cjs`：调色与上传动作的真实浏览器流程；同一检查接入打包应用回归。

JPEXS 库、JDK、Pillow、NumPy、SciPy、Sharp 和 Chromium 为离线转换依赖。Python 版本见 `scripts/art/requirements.txt`。导出器在缺少临时 XML 时从原件重建，并校验每个源 SHA。保留源件与来源散列，不能依赖临时目录里的输出作为唯一素材存档。
