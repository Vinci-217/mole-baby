# v0.31.9 验证记录

用户授权修复桌面涂鸦比例、自测后重新发布，并选择附带支持覆盖升级的固定签名安卓预览版。v0.31.8 标签的正式安卓验收发现间歇故障，发布被阻止，未创建公开 Release。保留原标签，以 v0.31.9 继续交付。

## 修复

沿用四形态、四种涂鸦的第一帧身体固定比例校准，完整保留源帧、帧率和动作内的伸缩；初级涂鸦一／二原先开场接近平时 1.96 倍。浏览器 64 组 DPR／形态／动作检查及原生窗口锚点检查见 [v0.31.8 记录](release-0.31.8-validation.md)，[前后截图](../docs/previews/v0318/tuya-after.png)和 [校准数据](tuya-size-calibration.json)。背包分类与物品同步渲染的修复同时保留。

Android 长按会产生 `contextmenu`，旧版把它当成桌面右键，意外打开背包，进而阻止收纳。新增移动浏览器回归在旧版稳定得到一个意外的 `companion-panel`，与原生失败现场一致。移动端现在阻止该右键快捷入口；桌面普通右键继续打开背包，已开始的拖动也不会被右键菜单打断。

测试保留全部原收纳／旋转／存档断言，另外增加真实手指长按与可信 pointerdown 检查。浏览器主动派发移动端 contextmenu，以覆盖系统是否实际生成菜单的差异；原生另外使用真实手指保持按住，检查原生与页面都没有意外打开背包。

## 验证范围

本地重新通过 540 项检查（388 Vitest、152 Node）及生产构建，1126 张图片无损处理并核对全部透明度／可见像素。四种手机／平板布局均通过新增菜单断言及原有领养、背包、课程、游戏、存档和悬浮桥接检查。新增 Android 手指长按测试由正式 CI 的完整 JDK 21 编译并在模拟器执行；本地原生编译因当前环境只有 JRE、缺少 Java 编译器而不能完成，不将其计为通过。

真实 Linux Electron 35.7.5 窗口另外通过右键检查：物理鼠标右键仍打开背包，移动端长按处理没有移除桌面快捷入口。

发布仍依赖 Windows 常规版、兼容 x64／ia32、Mac ARM／Intel、Android 全部成功；固定签名安装与覆盖升级后保留存档是安卓必需检查。开发／测试夹具不发布。正式结果与公开下载、签名指纹验证在完成后追加。

源提交 `0168faf0c80b6a922fb6b71a75c0ad3c4faae7ee` 的[正式流程](https://github.com/Vinci-217/mole-baby/actions/runs/41035372957)已完成 Android 检查：新增真实手指长按与既有拖动、无 Activity 旋转、边缘收纳、通知恢复、小屋往返全部通过。实际 APK 差量重建经过 SHA256 校验，再真实覆盖安装验证原生与页面存档。受控实验完整包 556,407,394 字节，复用 556,190,416 字节、下载 216,978 字节；这只代表该测试夹具，不代表未来公开版本的固定节省量。

## 候选未发布

Android 和 Windows 常规／兼容 64 位验收通过；兼容 32 位也通过完整应用运行检查，但随后安装器自动测试没有观察到 Finish 页，发布门槛因此阻止公开 Release。日志先记录 Install，随后又点击了 Next。测试会在安装启动后继续发送导航点击，而 NSIS 的共享按钮可能在转换到 Finish 时短暂保留 Next 标题，存在提前误点完成页的竞态。

后续测试修正为发送一次 Install 后只等待 Finish，不再点击进度期间的 Next；仍要求独立目录、原素材哈希、真实 Finish、向导隐藏和安装后的应用可见启动全部通过。未改写 v0.31.9 标签，后续以 v0.31.10 重新完整验收。[后续记录](release-0.31.10-validation.md)。
