# v0.31.5 发布验证

日期：2026-10-29（北京时间）。用户在审阅 Windows 透明背景修复预览后明确要求「帮我重新发版」，本轮已授权正式发布。

## 内容与来源

从 main 的 v0.31.4 基础准备 0.31.5，仅引入已验证的 Windows 软件合成兼容修复、生命周期断言、原生物理测量工具及证据。应用运行时代码与 `preview/windows-transparent-background` 的实测版本一致；版本号和发布说明同步。叶片与甩出动画的预览实验继续留在原预览分支，没有将其作为新客户端动画发布。

[三个 Windows 预览成品原生验收](https://github.com/Vinci-217/mole-baby/actions/runs/40882268188)在 100%／125%／150% Chromium 缩放下完成 84 次物理桌面采样，并用真实 HWND 黑块／白条阳性对照校准。旧正式版在相同云端机器也没有黑底，受影响 GPU／驱动没有在云端复现，不能宣称已验证所有真实硬件故障。[原始测量与范围](windows-transparency-2026-10-29.json)。

## 发布流程

正式流水线重新构建 Windows 常规 x64、兼容 x64／ia32、Mac arm64／x64。Windows 成品除了现有流程还验证实际 `gpu_compositing` 已禁用，且未禁用软件栅格化。全部成品、安装器、原生应用与更新流程通过后，校验十个成品，生成七份更新 blockmap，核对四种更新清单，再公开 Release 并切换 latest。

精确版本本地结果、正式流水线、公开附件和更新源核验将在完成后追加，不用预览构建的成功替代正式版本验收。

## 精确版本本地检查

0.31.5 的 381 项 Vitest、135 项 Node 检查共 516 项全部通过；生产构建通过。1126 张图片完成无损 WebP 压缩，并逐张校验可见 RGBA 与全部透明度一致。运行时代码和素材与 Windows 原生预览成品一致；新增正式成品软件合成状态断言。没有把 Linux 构建作为 Windows／Mac 原生包测试的替代。[本地检查回执](release-0.31.5-local-checks.json)。
